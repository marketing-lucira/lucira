ⓘ Agent Performance — Additional Honesty Notes

Modified Deals needs each Deal's Modified_Time field. It exists in the raw BigQuery CDC data but the live bundle query does not extract it yet, so this column reads N/A, not zero, until that backend query is updated and redeployed.   Deal Trigger Event buckets below use this CRM's real Deal_Trigger_Event vocabulary (WhatsApp, Chat, Payment, Checkout, Add to Cart, Abandoned Cart, Product View, Signup, Login, Forms, Schemes, Fresh, Closed) — an e-commerce funnel-event field, not a contact-channel field. There is no "Store Visit"/"Video Call"/"Phone Call"/"Reminder"/"Follow-up" vocabulary anywhere in this CRM's Deal data (those only exist as Zoho Meeting sub-types, already shown separately in Section 1/9).   Activities = Calls + Tasks linked to a Deal via What_Id; Zoho Meetings and Notes are not linked to Deals in this feed, so they're excluded rather than guessed.
